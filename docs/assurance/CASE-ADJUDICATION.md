## วิธีตัดสินที่ทำต่อได้

Owner ดู objective/setup/oracle ของแต่ละแถวเทียบ legacy test identity และเลือก SAME_CASE / VARIANT_SAME_LINEAGE / DISTINCT_OBJECTIVE พร้อม evidence refs
ถ้าแยกได้ว่าคนละ objective ต้องบอกเหตุผลเชิงพฤติกรรมก่อน preregister; source hash ต่างอย่างเดียวไม่ใช่เหตุผลเพิ่มสิทธิ์
ถ้าหลักฐานยังไม่พอ ใช้ UNRESOLVED และระบุหลักฐานที่ต้องเติม ไม่ขอให้ Owner รับรองว่าข้อมูลครบโดยไม่มีข้อมูล

## งานอื่นที่เดินคู่ขนานได้

กำหนด demo walkthrough และเตรียม host-control evidence plan ต่อได้ โดยไม่รอให้ทะเบียนนี้กลายเป็น production certification
Actual D05 dispatch ยังขึ้นกับ exact identity/budget/host/route; การจัดทำตารางไม่ grant exception
